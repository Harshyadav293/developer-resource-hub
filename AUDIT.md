# GDG AITR Portal Review & Suggestions

Portal reviewed: https://gdgocaitr.vercel.app/

## Purpose
This audit follows Section A of the GDGoC AITR Web Developer Recruitment Task. It focuses on broken links, text alignment, mobile responsiveness, visual glitches, and useful improvements.

## Important verification note
The portal URL could not be fetched from the development environment used to prepare this submission. Therefore, this document does **not** claim that a specific portal bug was observed when it could not be verified.

Before submission, open the portal yourself on a laptop and phone and replace the checklist statuses below with your own observations.

## Desktop checks

| Area | Status | What to check |
|---|---|---|
| Navigation links | Manual check | Open every navigation item and confirm it reaches the intended section/page. |
| Text alignment | Manual check | Check headings, buttons, cards and footer for inconsistent alignment. |
| Images | Manual check | Check for stretched, cropped or missing images. |
| Spacing | Manual check | Check for excessive empty space or cramped sections. |
| Buttons | Manual check | Confirm hover/click states and that buttons have clear actions. |
| Forms | Manual check | Check validation, labels and success/error feedback. |

## Mobile checks

Test at approximately 375px and 430px wide.

- [ ] Navigation does not overflow horizontally.
- [ ] Text remains readable without zooming.
- [ ] Buttons remain easy to tap.
- [ ] Cards stack correctly.
- [ ] Images do not overflow their containers.
- [ ] No horizontal scrollbar appears.
- [ ] Footer remains readable.
- [ ] Forms fit the screen.

## Suggested improvements

1. **Clearer event/resource discovery** — add prominent quick links or search so visitors can reach important information faster.
2. **Upcoming events section** — show the next events with date, venue, topic and registration CTA in one place.
3. **Mobile-first navigation** — use a compact mobile menu if the current navigation becomes crowded on smaller screens.
4. **Stronger accessibility** — use descriptive image alt text, visible keyboard focus states, semantic headings and sufficient contrast.
5. **Consistent call-to-action buttons** — use consistent labels such as `Register`, `Explore`, or `Join Community` so users immediately understand the next action.

## Final submission note
After the manual check, keep only findings that were actually observed and add screenshots for the most important 2–3 issues. The recruitment task asks for clear, actionable suggestions rather than a production-level redesign.
